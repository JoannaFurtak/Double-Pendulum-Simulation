# Double-Pendulum-Simulation
This repository contains a Python numerical simulation of a Double Pendulum. The project was developed by a 3-person team during a science camp organized by the Almukantarat Astronomy Club.  
### Key Features
* **Custom ODE Solvers:** Implemented both **Euler** and **4th-order Runge-Kutta (RK4)** methods from scratch.
* **Energy Conservation Analysis:** Compares the total mechanical energy over time for both numerical methods to evaluate their stability.
* **Visualization:** Generates plots of angular displacement and an animated GIF of the pendulum's motion.
